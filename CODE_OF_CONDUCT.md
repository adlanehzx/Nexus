# Code of Conduct

We are committed to providing an open, welcoming, and safe community. Everyone participating in
the project pledges to communicate respectfully, critique ideas rather than individuals, accept
constructive feedback, and protect private information encountered during code reviews.

Harassment, insults, intimidation, discrimination, publishing private information, and any
behavior that endangers individuals are strictly prohibited.

Maintainers may correct, hide, or remove contributions, and suspend accounts violating these
rules. Incidents can be reported privately via the contact methods on the GitHub maintainer's
profile. Reports will be handled confidentially and without retaliation.

This text is adapted from the Contributor Covenant 2.1:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
